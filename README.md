# Bitongue Adventures — Content Site Prototype

GitHub-ready static website inspired by the supplied Bitongue layout and the two supplied reading sheets.

## Included
- Vocabulary tab with links to the two supplied Quizlet sources.
- Reading tab using the two supplied PNG reading sheets.
- Listening tab with the three supplied YouTube resources.
- Speaking, Writing and Grammar interactive placeholders.
- Entrepreneurship / Project tab with a five-day editable structure.
- Responsive layout.
- Content and assets kept separate so later units/days can be added without redesigning the shell.

## Important
The Quizlet pages could not be retrieved reliably during this build, so their vocabulary was not scraped or invented. The site links to the source pages and leaves the activity data editable.

The supplied reading sheets are copied into `assets/reading/`.

## Run
Open `index.html` in a browser, or publish the folder with GitHub Pages.
